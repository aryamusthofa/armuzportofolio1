# Armuzportofolio — Arya Musthofa

Portofolio interaktif: **web yang bisa dimainkan**, bukan cuma dilihat.

**🔗 Live:** https://aryamusthofa.github.io/armuzportofolio1/

## ✨ Yang bikin beda

- **Playground** — scene ala proyek Remotion "Jendela Peluang", tapi versi web:
  scroll = timeline (dengan frame counter ala Remotion) · klik = efek partikel ·
  ketik = hurufmu muncul di layar
- **Custom cursor** — titik + ring pegas yang membesar di elemen interaktif
- **Kartu proyek 3D tilt**, marquee yang miring mengikuti kecepatan scroll,
  statistik count-up, dan judul hero yang bereaksi per huruf

## 🛠️ Tech

React 19 · TypeScript · Vite · Framer Motion · Lenis · Lucide

## 🚀 Jalankan lokal

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # production build ke dist/
```
